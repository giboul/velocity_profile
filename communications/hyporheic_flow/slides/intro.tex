        \column{0.5\linewidth}
            According to the (Gauckler-)Manning(-Strickler) formula, the bed's shear resistance is :
            $$\tau_p = \frac{\varrho g}{K^2}\frac{\bar{u}^2}{h^{1/3}}$$
            \begin{itemize}
                \item $\varrho$ : the fluid's density,
                \item $g$ : the gravitational acceleration,
                \item $K$ : a calibrated coefficient (depends on roughness),
                \item $\bar u$ : the mean flow speed and
                \item $h$ : the flow depth.
            \end{itemize}
    \end{columns}
